# PILOTO CON GLORIA — APRENDO A DECIR LO QUE SIENTO

## Preparación

- Probar primero sin Misión.
- Usar Chrome o Edge.
- Confirmar permiso de micrófono.
- Realizar la experiencia en un momento tranquilo.
- No explicar DESC antes de comenzar.
- No corregir emociones.

## Observación

Registrar únicamente:

- si comprende la situación;
- si avanza sin ayuda;
- qué pasos requieren apoyo;
- si desea grabarse;
- cuántos intentos realiza;
- si escucha su propia grabación;
- si la vergüenza disminuye;
- si comprende la frase final;
- si desea repetir o volver otro día.

## Aceptación inicial

El piloto puede considerarse positivo cuando:

- Gloria completa el recorrido;
- comprende la estructura básica;
- logra expresar una frase propia o guiada;
- la grabación aporta valor;
- no siente que está siendo examinada;
- el cierre resulta motivador;
- los datos quedan guardados;
- una Misión, si se usa, actualiza su progreso.

## Después del piloto

No modificar inmediatamente por cada observación.

Agrupar:

1. fallos;
2. dificultades reales;
3. mejoras simples de alto valor;
4. ideas futuras.

Actualizar el producto solo después de distinguir entre un caso puntual y una necesidad repetible.
